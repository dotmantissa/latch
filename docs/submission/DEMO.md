# Recorded demonstration

The recording shows real browser automation against the publicly deployed Vultr application and a fresh supplier inspection. It does not portray automation as a human buyer's approval.

1. Open the public app and start a private demo session.
2. Create the labelled U6+ public source demonstration. Review the public inference disclosure and agree before capture.
3. Start an actual inspection. Its plan, sandbox capture, text extraction and screenshot correspondence are persisted through the durable runner.
4. Open source evidence and image correspondence. Show unresolved terms and enforced product image abstention. Compare the basket without inventing a total or releasing an order.
5. Show a real containment attempt and the timestamped actual worker diagnostic: metadata, private, loopback and direct network access fail; the watchdog terminates a task and cleanup is confirmed.

The live demo has a deliberately narrow admitted source. Shipping, tax, arrival, exclusions and product photographs are not assumed. Review can record an unknown term; it cannot convert missing evidence into a complete quote.

The app does not buy anything, submit a supplier form, send email or use supplier credentials. Release creates an internal decision record after renewed evidence and database authority checks.
