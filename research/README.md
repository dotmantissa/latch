# Research archive

[The earlier planning bundle](prior-plan/README.md) preserves the research, judge scrutiny and product revisions that led to Latch. QuoteProof is the retired working name.

These documents are historical. Their synthetic offers, reference calculations, old dual execution design and numerical candidate scores do not describe an implemented product or current acceptance evidence. The canonical scope is [ARCHITECTURE.md](../ARCHITECTURE.md).

The model catalog snapshot is public metadata retrieved on November 3. It does not prove account access, model quality or latency. Actual model and source verification remains an implementation gate.

No historical source or example is automatically shipped to the frontend, seeded into a database or counted as a real buyer outcome.
