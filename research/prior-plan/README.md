# QuoteProof: purchase review and release

**Revised direction:** help an IT deployment coordinator review a complete equipment basket and recheck supplier terms before releasing a versioned internal purchase request.

The agent inspects supported supplier pages and terms, captures evidence and proposes normalized fields. Trusted code handles costs, completeness, deadlines and approval. Release triggers a fresh capture; changed or unavailable terms prevent release under the old approval.

The synthetic demo equips 25 workstations within seven days and a $10,000 budget. A's $4,950 quote omits docks, C's $8,960 offer arrives late, and B's complete offer costs $9,500. When B changes to $9,875 after approval, a source recheck discovers it and requires fresh review. These are illustrative offers, not customer evidence or measured savings.
